# Identity platform
Customer identity and access management. For end users that are using your applications.

### Cloud IAM vs Identity Platform
Cloud IAM: employees and partners authorization
Identity platform: customer identity and access management (CIAM)

### Key features
- Authentication and authorization for web & mobile apps
- Multiple authentication methods
- Sign up and sign in, MFA etc



# Event Driven Architecture
Micro-services reacting to changes in state (events).

### Advantages
- loose coupling
- flexibile orchestration
- resiliency
- async

## Cloud Events 
Standard specification to describe events.


# Eventarc
Simplifies event driven architecture in Google Cloud.
Deliver events from Google services, SaaS and your own apps.
Eventarc uses loosely coupled services that react to state changes and requires no infrastructure management.

Adheres to CloudEvents spec.

Used Pub/Sub in background.


# Open Telemetry

Collection of technologies (tools, APIs, SDKs) to collect and export telemetry (metrics, traces and logs)
- Open standard
- Cloud Native Computing Foundation project
- Almost every platform support Open Telemetry


# Service Discovery
Help micro-services find each other.
A single place in Google Cloud to publish, discover and connect services.
