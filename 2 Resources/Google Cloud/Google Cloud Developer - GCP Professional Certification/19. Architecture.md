## Streaming data - realtime

- **Pub/Sub:** receive messages
- **Dataflow**: analyze, aggregate and filter data 
- Pre-defined time series analytics, storing data in **Bigtable** gives you the ability to perform rapid analysis
- For ad hoc complex analysis, prefer **BigQuery**


## IoT

- IoT Core - manage IoT (registration, auth) devices
- Pub/Sub: durable message ingestion service
- Dataflow: processing data
- Data storage and analytics
	- IoT data available on mobile or web apps -> Datastore
	- Execute pre-defined time series queries -> BigTable
	- More complex or ad hoc analysis -> BigQuery
