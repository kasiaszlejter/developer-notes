## Pub/sub
- Reliable, scalable, fully-managed async messaging service
- Highly available and scalable
- Low cost
- Support push and pull messages

### Publisher - sender of the message

- Sends messages by making HTTPS requests to pubsub.googleapis.com

### Subscriber - receiver of the message

 - Pull - subscriber pulls messages when ready
 - Push - subscribers provide web hook endpoints at the time of registration, when a message is received on the topic, a HTTPS POST request is sent to the web hook endpoints

Very flexible

## Cloud Tasks

Manage execution, dispatch and delivery of a large number of distributed tasks async.
Supports tasks targetting any HTTP service running on:
- Compute Engine
- Google Kubernetes Engine
- Cloud Run
- Cloud Functions
- On-premise systems


### Difference between Cloud Tasks and Pub/Sub

Pub/Sub
Implicit invocation - pull and push models

Cloud Tasks
Explicit invocation - only push models
